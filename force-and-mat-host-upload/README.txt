FORCE & MAT — deploy instructions

This is a static website. The homepage is index.html.
To publish: upload the contents of this folder (or this ZIP) to a static host such as Netlify Drop.

Important: the current login screen is a front-end demo only. It does not create secure accounts or sync data between devices. Workout data is stored in the browser's local storage.
The page loads React, Tailwind CSS, Babel and Lucide from public CDNs, so an internet connection is needed when opening the site.
